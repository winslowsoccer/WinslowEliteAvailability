Sparks Availability

Instructions:

  • Select your name from the drop-down list.
  • Select the weekend you would like to set your availability.
  • Click on each time slot you are available for the day. If viewing on mobile device, scroll down to see Sunday times.
  • Repeat steps 2 and 3 for each weekend of the season.
  • Once completed, scroll to the very bottom and select "Submit All Weekends".

You will be able to go back and view your selected times at any time and be able to modify them. If you modify times, you will need to "Submit All Weekends" again.
